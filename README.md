# House Prices: 

Предсказываем цену продажи дома для соревнования Kaggle House Prices. Регрессию, обработка признаков, кросс-валидация и нейросеть.

## Установка в Windows PowerShell

Из папки проекта, с Python 3.13:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

В текущем рабочем окружении проект проверяется на Python 3.13; PyTorch для этого проекта работает на CPU. Для Jupyter выберите соответствующее ядро окружения. Файлы Kaggle `train.csv` и `test.csv` должны лежать рядом с `config.json`.

На этом компьютере уже создана папка `.venv` с доступом к установленным системным пакетам, чтобы повторно не скачивать PyTorch и остальные библиотеки. Поэтому изменение системных пакетов может повлиять на это окружение. Команды выше создают обычное изолированное окружение на другом компьютере.

## Запуск одной командой

```powershell
.\.venv\Scripts\python.exe main.py
```

По умолчанию запускается CatBoost с параметрами, найденными в ноутбуке. Проверка идёт на пяти фолдах, затем модель обучается на всём train и создаёт файл для Kaggle. При активированном окружении можно использовать `python main.py`.

```powershell
python main.py --task ml --model ridge
python main.py --task ml --model catboost,random_forest,svr
python main.py --task ml --model all
python main.py --task dl
python main.py --task all
python main.py --config config.json
```

`--task all` запускает выбранные в конфиге ML-модели и PyTorch MLP. `--model all` запускает все настроенные ML-модели и может работать долго. Параметры и список моделей можно изменить в `config.json`. Доступны `catboost`, `ridge`, `lasso`, `elasticnet`, `svr`, `knn`, `decision_tree`, `random_forest`, `gradient_boosting`. Поиск GridSearch и Optuna автоматически не запускается.

## Результаты

Для каждого запуска создаётся новая папка `outputs/<дата_время>/`:

- `run.log` — ход запуска и ошибки;
- `config.json` — настройки конкретного запуска;
- `fold_scores.csv` — RMSE каждого фолда;
- `results.csv` — средний RMSE и стандартное отклонение;
- `submission_ml_<модель>.csv` и/или `submission_dl_mlp.csv` — прогнозы каждой модели;
- `submission.csv` — прогноз модели с наименьшим средним RMSE среди моделей этого запуска.

Папка создаётся до обучения, поэтому при ошибке журнал остаётся доступен. `submission.csv` содержит `Id` и `SalePrice` в долларах; файл не отправляется на Kaggle автоматически.

В корне проекта `experiment_results.csv` — сохранённая таблица из ноутбука `experiments.ipynb`. Файл использует разделитель `;` и кодировку UTF-8 с BOM, чтобы его было удобнее открыть в Excel. В нём есть результат PyTorch с ранней остановкой на одном фолде: его нельзя напрямую сравнивать со средним результатом по пяти фолдам. Некоторые значения в таблице ранее были восстановлены вручную и округлены. Чтобы обновить файл после новых экспериментов в ноутбуке:

```python
results_table.to_csv('experiment_results.csv', sep=';', index=False, encoding='utf-8-sig')
```

## Как устроена проверка

Цель преобразуется через `log(SalePrice)`. Пять фолдов KFold перемешиваются с seed 42. RMSE считается по логарифмам, как в соревновании; перед сохранением цен применяется `exp`. Для sklearn и PyTorch пропуски чисел заполняются медианой, числовые значения масштабируются, пропуски категорий заполняются строкой Missing, а категории кодируются One-Hot. Обработка обучается отдельно внутри каждого фолда. CatBoost получает категории напрямую; пропуски в них заменяются Missing.

MLP использует CPU, Adam и фиксированное количество эпох без ранней остановки. Случайное начальное состояние фиксируется, но точное совпадение на разных версиях библиотек и устройствах не гарантируется. Число эпох и прочие параметры можно менять в конфиге.

Лучший CatBoost в ноутбуке показал CV около 0,12719 и первую публичную оценку Kaggle 0,12463. Эти результаты используются как ориентир, а не как гарантия повторения. После многократного подбора на тех же фолдах CV-оценка может быть оптимистичной.
